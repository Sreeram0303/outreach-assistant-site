Outreach Assistant

A personal Telegram assistant that turns a job or founder post into a short, personalised email with the right resume attached. The user previews every email and taps Send; nothing is sent without that explicit confirmation.

How it uses Google

The app requests one Gmail permission, gmail.send, which lets it send an email from the user's account only after the user confirms that exact email. It cannot read, search, modify or delete any email in the mailbox.

It is a personal, non-commercial project used by its developer and a small number of invited testers.
